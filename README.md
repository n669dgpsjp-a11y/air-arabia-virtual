# Air Arabia Virtual

Responsive website for an unofficial Roblox virtual airline inspired by Air Arabia's modern web experience.

## Current build
- Responsive desktop and mobile homepage
- Virtual flight search demo
- Destination cards
- Route, flight status, travel guide and community expansion points
- Careers section
- Clear unofficial/fan-made labelling

## Files
- `index.html` — page structure
- `styles.css` — responsive design system
- `app.js` — interactions and demo flight search

## Roadmap
The project can be expanded with schedules, virtual bookings, flight status, fleet and destination databases, Roblox/community links, staff applications, member accounts and an admin dashboard.

## Disclaimer
This is an unofficial fan-made Roblox aviation project. It is not affiliated with Air Arabia PJSC and does not offer real-world flights, tickets, payments or commercial airline services.
